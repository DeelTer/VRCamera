# Справочник VRCamera

[Вернуться к README](../README_RU.md) · [English version](GUIDE.md)

Управление и настройки для VR и ПК. Для игры без шлема см. [Без VR](#без-vr).

**Для VR:** включите в Vivecraft **«Показ Модели Игрока»** (VR Settings → «Настройки Модели Игрока»).
Без этого персонажа нет в кадре камеры.

Все дистанции камеры умножаются на атрибут игрока `scale`. Мод переведён на английский, русский, украинский,
немецкий, французский, испанский, бразильский португальский и упрощённый китайский.

## Управление

| Действие                             | Клавиша      | В шлеме                                           |
|--------------------------------------|--------------|---------------------------------------------------|
| Переключить режим                    | `F8`         | кнопка в меню паузы                               |
| Следующий план                       | `F9`         | экран «VR-камера...»                              |
| Удерживать текущий план              | `F10`        | экран «VR-камера...»                              |
| Следующий свой ракурс                | `F7`         | экран «VR-камера...»                              |
| Сделать фото                         | `F6`         | привязать к кнопке контроллера или `/vrcam photo` |
| Камеру ко мне                        | не назначена | экран «VR-камера...»                              |
| Новый свой ракурс / свободная камера | `N`          | экран «VR-камера...»                              |
| Удалить свой ракурс                  | —            | экран «VR-камера...»                              |
| Управлять камерой ПК                 | `G`          | только ПК                                         |
| Повернуть камеру/фото в руках        | `R`          | только ПК, пока держите                             |
| Пролёт к следующей свободной камере  | не назначена | только ПК                                         |
| Отладочный оверлей                   | не назначена | экран «VR-камера...»                              |
| Меню VR-камеры                       | не назначена | радиальное меню или кнопка контроллера            |
| Настройки                            | не назначена | экран «VR-камера...», нужен Cloth Config          |

Клавиши — обычные привязки Minecraft. Их можно переназначить в настройках управления или привязать к кнопкам
контроллеров в SteamVR. Они работают, когда окно игры в фокусе и меню закрыто, так что камерой может управлять
человек за компьютером, пока игрок в шлеме.

### Команды

`/vrcam` делает то же самое, с подсказками по Tab. Команда выполняется на клиенте и прав не требует.

| Команда                                           | Что делает                                                                                                                                                        |
|---------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `/vrcam`, `/vrcam status`                         | пишет то же, что показывает отладочный оверлей                                                                                                                    |
| `/vrcam off`, `director`, `follow`, `physics`     | включает этот режим                                                                                                                                               |
| `/vrcam mode`                                     | следующий режим                                                                                                                                                   |
| `/vrcam next`                                     | следующий план                                                                                                                                                    |
| `/vrcam hold`                                     | удерживает или отпускает текущий план                                                                                                                             |
| `/vrcam shot <имя>`                               | показывает план: `shoulder`, `front`, `orbit`, `flyby`, `crane`, `low`, `hands`, `duel`, `death`, `fall`, `pov`, `menu`, `custom`. Включает режиссёра, если нужно |
| `/vrcam summon`                                   | камеру ко мне                                                                                                                                                     |
| `/vrcam photo`                                    | делает фото                                                                                                                                                       |
| `/vrcam load <адрес>`                             | помещает картинку из интернета на листок                                                                                                                          |
| `/vrcam preset next`, `new`, `delete`             | свои ракурсы                                                                                                                                                      |
| `/vrcam preset <номер>`                           | выбирает свой ракурс, считая с 1                                                                                                                                  |
| `/vrcam debug`                                    | отладочный оверлей                                                                                                                                                |
| `/vrcam settings`                                 | экран настроек, нужен Cloth Config                                                                                                                                |
| `/vrcam pace alpha`, `default`, `faster`          | задаёт темп режиссёра, см. «Настройки»                                                                                                                            |
| `/vrcam screen director`, `follow`, `free`, `off` | камера без VR, в окне игры                                                                                                                                        |
| `/vrcam screen steer`                             | взять камеру на клавиши ходьбы или отдать её                                                                                                                      |
| `/vrcam chroma`                                   | включает и выключает хромакей                                                                                                                                     |
| `/vrcam reload`                                   | перечитывает файл настроек                                                                                                                                        |

Команды режимов, планов и своих ракурсов из таблицы управляют камерой Vivecraft и требуют его установки. Для
камер ПК используйте `/vrcam screen` и команды `/cam` из раздела [Без VR](#без-vr).

`/vrcam shot` показывает план, даже если он выключен или не подходит ситуации. План длится как обычно, потом
режиссёр продолжает сам. Чтобы план остался, выполните после него `/vrcam hold`.

В шлеме клавиатуры нет. Добраться до всего этого из VR можно двумя способами:

- **Радиальное меню.** Любую клавишу из таблицы выше можно положить в радиальное меню Vivecraft: VR Settings →
  «Радиальное меню...», нажать на ячейку и выбрать клавишу из группы «VR-камера». Клавиши без назначенной кнопки
  там тоже работают. Под рукой стоит держать: «Удерживать текущий план», «Следующий план», «Переключить режим камеры»,
  «Камеру ко мне», «Сделать фото». Или одну: **«Открыть меню VR-камеры»** — экран, где есть всё это.
- **Кнопки контроллера.** Те же клавиши видны в привязках контроллеров SteamVR у Vivecraft, их можно назначить
  на кнопку напрямую.

В быстрые команды Vivecraft (Quick Commands) можно положить и команды `/vrcam`. Они появятся под кнопкой
**Commands** в меню паузы, и каждую можно привязать к кнопке контроллера в SteamVR.

## Камера в руках

Это управление работает во всех режимах VR.

**Взять и поставить.** Зажмите взаимодействие рядом с камерой. При отпускании «Следование» сохраняет положение
относительно вас, «Режиссёр» удерживает ракурс на `manualHoldSeconds`, а «Физика» роняет камеру.
Режиссёр и следование запоминают позицию, но продолжают смотреть на игрока.

**Бросить.** Взмахните и отпустите. Бросок срабатывает при скорости руки выше 2,5 блока/с;
`throwPower` задаёт силу (0 выключает). Работает и с обычной камерой Vivecraft при выключенном моде.

**Притянуть.** Посмотрите на камеру и наведите руку. После вибрации контроллера зажмите взаимодействие.
Камера ускоряется к руке за `pullSeconds` (по умолчанию 1,25 с) и остаётся в ней до отпускания кнопки.
Дальность — от 1,5 до 64 блоков; камера на земле поднимается по дуге.

- Отпустите раньше в «Физике»: камера сохранит скорость и упадёт.
- В «Режиссёре» и «Следовании» она останется там, куда долетела. До начала движения — ничего не произойдёт.
- Взмахните при отпускании, чтобы бросить её в любом режиме.
- `pullStyle: "instant"` переносит камеру сразу после удержания кнопки.
- Для защиты от случайного захвата в режиссёре и следовании задайте `pullAllModes: false`.

**Камеру ко мне** ставит её на расстоянии вытянутой руки на 20 секунд.
`handStabilize` сглаживает запись, но модель камеры в шлеме остаётся в руке (0 выключает).
Рука, держащая камеру, скрыта из записи, кроме селфи; `hideHoldingArm: false` отключает это.

### Свои ракурсы

Ракурсов, поставленных рукой, может быть несколько. Постановка рукой всегда записывается в активный.

- **Новый ракурс** копирует активный и делает копию активной. После этого поставьте камеру.
- **Следующий свой ракурс** переключает их по кругу, камера перелетает.
- **Удалить ракурс** удаляет активный. Последний остаётся.

Обычный порядок: «Новый ракурс» → «Камеру ко мне» → взять, поставить, отпустить.

## Режим «Физика»

Для «найденной плёнки» и хоррора: камера — предмет, который держат в руке.

- Держите её, и она снимает туда, куда направлена рука. В шлеме она выглядит как камера Vivecraft с экранчиком.
- Отпустите, и она падает, отскакивает и кувыркается. Скорость руки сохраняется, так что её можно бросить.
- Отпустите медленно прямо над блоком, и она встанет на него: остаётся как держали и снимает туда, куда навели.
- По лежащей камере рука бьёт только быстрым взмахом. Если просто тянуться к ней, она не отлетает.
- Пока камера успокаивается, она доворачивается объективом к вам и остаётся лежать с завалом. Иначе она почти
  всегда снимала бы землю или небо. Насколько доворачивается, задаёт `physicsAim`: 0 — лежит как упала, 1 — смотрит
  прямо на вас.
- Остановившись, она за вами больше не следит. Отойдите и войдите в кадр.
- От мобов, лодок и вагонеток она отскакивает как от блоков. Упав на лодку или вагонетку, едет вместе с ней.
  Её можно уронить в лодке, в которой сидишь.
- Лежащую камеру отбрасывает тот, кто в неё вошёл: вы, моб, лодка. Медленный шаг её не трогает.
- Руки и ноги бьют по брошенной камере, в воздухе и на земле: её можно пнуть или набивать как волейбольный мяч.
  Камера, упавшая на неподвижную руку, от неё отскакивает. Для ног нужен трекинг всего тела. Силу задаёт
  `kickPower`, 0 выключает.
- Камера в руке покачивается от дыхания, сильнее — от шагов, и вздрагивает, когда вас бьют. Силу задаёт
  `physicsShake`.
- Когда вы умираете, камера выпадает из руки и доворачивается так, чтобы в кадре были тело и убийца.
- При ударе дёргается зум, слышен звук блока и летит его пыль. Пыль появляется только позади объектива: вы её
  видите, камера — нет.
- В воде и лаве она тонет медленно. Если блок под ней сломали, падает дальше.
- Под водой она снимает с более широким углом, в том числе в руке. Тонущая камера медленно покачивается
  вместо кувырков и оставляет пузыри. `underwaterLook` это выключает.
- Дальше 40 блоков она возвращается к вам: Vivecraft прячет слишком далёкую камеру.
- При включении режима камера появляется перед лицом на 20 секунд. Не взяли — падает.

Режиссёр, свои ракурсы и события в этом режиме не работают.

**Закрепить камеру.** В режиме «Физика» камеру можно не только положить, но и повесить. Поднесите её вплотную
и медленно отпустите:

- **К стене или потолку** — остаётся висеть так, как вы её держали. Упадёт, если сломать блок или ударить по ней.
- **К существу или игроку** — едет вместе с ним и покачивается при ходьбе, как в руке (`physicsShake`). У головы
  камера поворачивается и кивает вместе с головой, на теле — вместе с телом.
- **Себе на лоб** — поднесите к голове. К остальному своему телу камера не липнет, чтобы не цепляться случайно.

Снять — взять рукой или сбить ударом.

Камеру, которая тонет и падает на рыбу, спрута, дельфина или аксолотля, тот уносит на голове. Существо, на
котором оказалась камера, в этот момент подаёт голос.

## Планы

| Ключ       | Что делает                                           | Когда выбирается чаще                 |
|------------|------------------------------------------------------|---------------------------------------|
| `shoulder` | сзади, из-за плеча                                   | движение, полёт, тесные места         |
| `front`    | спереди, пятится; наезжает, пока вы стоите           | простой, ходьба                       |
| `orbit`    | медленно облетает игрока                             | простой, бой                          |
| `flyby`    | стоит впереди по пути и провожает поворотом, с зумом | бег, полёт, езда                      |
| `crane`    | поднимается высоко позади игрока                     | открытые места, полёт                 |
| `low`      | от земли, снизу вверх                                | бой, бег                              |
| `hands`    | крупный план рук                                     | копание, простой                      |
| `duel`     | из-за плеча на противника, оба в кадре               | бой с целью                           |
| `death`    | облетает погибшего и отъезжает                       | только при смерти                     |
| `fall`     | почти отвесно сверху                                 | только при долгом падении             |
| `pov`      | от первого лица: прямо перед лицом                   | там, где больше ни для чего нет места |
| `menu`     | близко из-за плеча на открытое меню                  | пока открыто меню                     |
| свой       | ракурс, поставленный рукой                           | режим «Следование»                    |

## Как работает режиссёр

Режиссёр подбирает планы и расстояния под ваши действия: стояние, ходьбу, бег, полёт, езду, плавание, бой и
добычу блоков. В тесноте чаще выбирает близкие ракурсы.

Расстояния по умолчанию для `shoulder`, `front` и `low` — 6, 6,2 и 5,6 блока. Сохранённые настройки важнее.

План меняется, когда истекает его время, стены слишком близко прижимают камеру, начинается новое действие или
вы нажимаете `F9`. Добыча должна длиться больше секунды. Переходы — склейки или плавные пролёты. Похожие планы
подряд не выбираются; камера старается сохранять направление движения в кадре. Телепорт сохраняет ракурс,
кроме неподвижного `flyby`. `F10` удерживает план и приостанавливает автоматические смены и события.

**Бой.** Удар по живому существу, в том числе взмахом контроллера, или его удар по вам задаёт цель.
Она сбрасывается после 5 секунд без боя, при смерти или удалении. Урон от падения и огня не учитывается.

**События:**

- Смерть: `death` до возрождения, по возможности с убийцей в кадре.
- Долгое падение: `fall`, когда под падающим игроком больше 6 блоков воздуха; ещё секунду после приземления.
- Взлёт на элитре: повышает шанс `flyby` при следующей смене.
- Открытое меню: `menu` снимает игрока и меню через плечо с большей свободой. Если места нет с обеих сторон,
  включается первый вид. `menuShotChat` включает чат. В VR меню размещает Vivecraft, на ПК нужно отдельное окно.

Если плечо закрывает меню, уменьшите `azimuth` плана `menu` (по умолчанию 138; 180 — прямо сзади). `leadRoom`
оставляет место впереди при движении; 0 центрирует игрока.

На ПК `povHome` делает первый вид основным и изредка вставляет другие планы; `povHomeSeconds` задаёт
длительность первого вида. `/cam with Имя` добавляет планы с напарником.

## Как камера избегает блоков

- От середины тела к нужной точке идут восемь лучей. Если на пути блок, камера встаёт перед ним.
- Придвигается она сразу, отодвигается плавно.
- Тонкое препятствие — ствол, столб — камера игнорирует до `softOcclusionTime` секунд, если сама стоит в свободном
  месте. В блок она не заходит никогда.
- В лаву и рыхлый снег она не встаёт, пока вы сами не в них.
- Если камера прижата дольше `occlusionCutTime`, режиссёр меняет ракурс.

Обход камера не ищет. Режиссёр выбирает ракурс, с которого вас видно.

Когда места нет ни для одного ракурса, например в туннеле в один блок, включается `pov`. Камера стоит в трети
блока перед лицом, а не в глазах: там она видела бы голову модели игрока изнутри. Насколько впереди, задаёт
`distance` этого плана.

## Фото

Держите камеру и зажмите вторую кнопку той же руки: курок, если держите за grip, или grip, если держите
курком. Контроллер вибрирует всё сильнее, и через `photoHoldSeconds` секунд (по умолчанию 1) щёлкает затвор.
Следующее фото можно сделать, когда листок этого уже покинул камеру.

Жест выбирает `photoGesture`:

| Значение       | Жест                                                                                                                                                         |
|----------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `"same_hand"`  | вторая кнопка руки, которая держит камеру. Нужен SteamVR; кнопка определяется по тому, к чему ещё она привязана, поэтому она должна быть к чему-то привязана |
| `"other_hand"` | поднести вторую руку к камере и зажать её кнопку взаимодействия. Чтобы перехватить камеру, возьмитесь второй рукой и отпустите первую                        |
| `"off"`        | только клавиша и команда                                                                                                                                     |

Если свободной руки нет или камера не в руке: клавиша `F6`, кнопка контроллера, к которой вы её привязали, или
команда `/vrcam photo`. Фото работает в любом режиме, пока камера включена.

- Фото — это то, что камера снимает в этот момент, в полном размере. Сохраняется в `screenshots/vrcamera`.
  Эти файлы мод никогда не удаляет.
- Щёлкает затвор, картинка на миг дёргается. В само фото рывок не попадает.
- Из-под камеры выезжает листок с фото, немного висит, потом планирует на землю. Его видно в шлеме и в записи.
  Другие игроки видят его только на серверах с плагином обмена фото.
- `photoSheet: false` — фото только сохраняется.

### Листки

- **Проявка.** Свежий листок пустой, картинка проступает за несколько секунд.
- **Взять.** Поднесите руку к листку и зажмите кнопку взаимодействия, как с камерой. Другая рука так же может
  забрать его из первой.
- **Бросить.** Отпустите в движении.
- **Закрепить.** Приложите листок обратной стороной к блоку и медленно отпустите: он прилипнет так, как вы его
  держали. Ровно, боком для вертикального кадра или под углом; ближе 7° к ровному он выравнивается. Таблички
  и флаги тоже подходят, а на голове, стоячей табличке и флаге листок встаёт по тому, как они повёрнуты.
  Чтобы перевесить, возьмите его снова.
- **Значок.** У листка, который падает или лежит, есть значок с расстоянием, как у камеры. У закреплённых нет.
- **Огонь и лава** сжигают листок.
- **Отрывается.** Если блок, на котором висит листок, сломали, листок падает. Взрыв срывает и разбрасывает
  листки, каждый по-своему. Сорванный листок снова ничей: закрепите его заново, иначе он забудется.
- **Что сохраняется.** Только закреплённые листки: в следующий раз в этом мире они будут на месте. Листок,
  оставленный лежать, забывается, когда его чанк выгружается или вы выходите; одновременно лежит не больше 12.
  Само фото в `screenshots/vrcamera` остаётся в любом случае.

Листки работают и при выключенной камере.

Закреплённые листки и их уменьшенные картинки хранятся отдельно для каждого мира в `vrcamera/sheets`. Когда
одиночный мир удалён, его папка там удаляется при следующем запуске игры. Папки серверов остаются: исчезнувший
сервер не отличить от того, на который вы просто сейчас не зашли. Если картинки в папке нет, её листок
убирается.

### Картинки из интернета

`/vrcam load <адрес>` помещает картинку из сети на листок и роняет его перед вами. Дальше это обычный листок:
его можно взять и закрепить.

- PNG, JPEG или первый кадр GIF, до 8 МБ, только `http` и `https`.
- Картинка обрезается из середины до ближайшей формы листка: 16:9, квадрат или 9:16.
- Скачанный файл сохраняется как есть в `screenshots/vrcamera/custom`.
- Адрес открывает только ваша игра, и сайт видит ваш IP, как в браузере. Другие игроки адрес не получают —
  только маленькую картинку, которую сделал из него сервер.

На сервере такой листок помечен как custom. Другие игроки видят на его месте чёрный листок с подписью
«Картинка скрыта вашими настройками» и названием нужной настройки, и их игра картинку не скачивает, пока они
не включат `showCustomPhotos`. По умолчанию выключено: это не фото из игры, на них может быть что угодно.

Метку ставит клиент, который загружает картинку. Она отделяет честных игроков от остальных; от того, кто
изменил игру, чтобы соврать, она не защищает. Сервер не может отличить скриншот от любой другой картинки.

Кому можно, решает сервер: право `vrcamera.custom`, которое по умолчанию есть у всех, и `custom-pictures` в
конфиге плагина, который выключает это для всех. `/vrcamsync purgecustom` удаляет все закреплённые картинки из
интернета.

### Общие фото на сервере

На сервере с плагином **VRCamera** (Paper) закреплённые листки общие: их видят все, у кого есть мод, и они
остаются, когда вы выходите. Jar плагина собирается вместе с модом — `vrcamera-sync-<версия>.jar` в
`build/libs/`. Положите его в папку `plugins` сервера. Игроки без мода ничего не видят, и на них это не
влияет.

- Закреплённые листки сервер хранит, они остаются.
- Незакреплённые — в руке, падающие, лежащие — тоже видны другим, но сервер держит их только в памяти:
  не больше 8 на игрока, исчезают, когда владелец вышел, сменил мир или 10 минут к ним не прикасался.
- Любой игрок в VR может подобрать чужой незакреплённый листок. С этого момента он его, и его можно закрепить.
- Игрок не в VR делает фото того, что видит, клавишей фото (`F6`). Листок падает перед ним. Подобрать его сам он
  не может, игрок в VR может. У него лежит не больше 3 листков, старые исчезают.
- Свои листки снимаете вы. Чужие — только если сервер разрешает.
- Если блок под листком сломали или взорвали, листок падает у всех.
- Сервер может отказать: слишком много ваших листков, слишком много в этом месте или слишком быстро. Тогда
  листок отваливается, а сообщение говорит почему.
- `showOthersPhotos: false` показывает только ваши фото. Ваши при этом по-прежнему видны другим.
- Игроки в пределах 32 блоков видят вашу камеру там, где она есть, — в руке или в полёте, со значком
  камеры и вашим ником над ней. `shareCamera: false` скрывает её от них.
- Игрок с модом, но не в VR, тоже видит закреплённые листки и камеры, но взять ничего не может.

За счёт чего это не грузит игру:

- Клиент узнаёт о листке в нескольких десятках байт, когда подходит на 32 блока. Сама картинка запрашивается
  только ближе 16 блоков и выгружается из памяти дальше 24.
- Картинки идут в JPEG, 256 пикселей в ширину, около 10 КБ. Каждая скачивается один раз и хранится на диске
  в `vrcamera/remote`, не больше 1000 штук.
- В памяти одновременно не больше 48 чужих картинок, ближайшие.
- Сервер отправляет игроку не больше 4 картинок в секунду.

Настройки сервера, `plugins/VRCamera/config.yml`:

| Настройка                        | По умолчанию  | Значение                                                                                                                                                      |
|----------------------------------|---------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `limits.per-player`              | `64`          | сколько листков может закрепить один игрок                                                                                                                    |
| `limits.per-chunk`               | `24`          | сколько листков в одном чанке, всех игроков вместе                                                                                                            |
| `limits.loose-per-player`        | `8`           | сколько незакреплённых листков игрока видят другие; `0` — только владелец                                                                                     |
| `limits.loose-minutes`           | `10`          | через сколько минут исчезает листок, к которому не прикасались                                                                                                |
| `limits.total`                   | `20000`       | сколько листков на всём сервере                                                                                                                               |
| `limits.image-bytes`             | `20000`       | самая большая картинка, которую может прислать клиент                                                                                                         |
| `limits.pin-cooldown-ms`         | `1500`        | пауза между двумя закреплениями одного игрока                                                                                                                 |
| `photos.cooldown-seconds`        | `3`           | пауза между двумя фото одного игрока; щелчок его камеры раньше не передаётся. `0` — без паузы |
| `anyone-takes-off`               | `false`       | `true` — любой может снять любой листок                                                                                                                       |
| `custom-pictures`                | `true`        | `false` — никто не может вешать картинки из интернета                                                                                                         |
| `worlds.mode`, `worlds.list`     | `deny`, пусто | в каких мирах можно закреплять и раздавать фото. `deny` — везде, кроме перечисленных миров. `allow` — только в перечисленных. Уже висящие фото остаются       |
| `photos-protect-blocks`          | `true`        | `true` — блок с фото не взрывается, не сгорает, не двигается поршнем и не опадает. Игрок сломать может. Любой сможет сделать блок взрывостойким, повесив фото |
| `range.send`, `range.forget`     | `32`, `48`    | на каком расстоянии клиентам сообщают о листках и после какого они их забывают                                                                                |
| `network.images-per-second`      | `4`           | картинок одному игроку в секунду                                                                                                                              |
| `cameras.share`, `cameras.range` | `true`, `32`  | показывать камеры игроков остальным и в скольких блоках                                                                                                       |
| `cameras.free-through-blocks`    | `false`       | `false`: свободная камера ПК-игрока упирается в блоки, а не пролетает сквозь них |
| `cameras.free-range`             | `64`          | на сколько блоков свободная камера отходит от игрока, дальше её тянет за ним. `0` — без предела |
| `mod.min-version`                | `2.1.3`       | самая старая версия мода, с которой пускает; более старая не знает правил камеры |
| `mod.kick-outdated`              | `true`        | `true`: игроков с более старым модом кикает; `false`: только сообщение |
| `mod.outdated-message`           | см. конфиг    | текст кика или сообщения; `%min%` — версия |

Права: `vrcamera.pin` (все), `vrcamera.photo.nocooldown`, `vrcamera.camera.unrestricted`,
`vrcamera.remove.others`, `vrcamera.admin` (все четыре — операторы).
Запретить съёмку в каком-то месте, например на арене: `/vrcamsync camera deny <игрок>` и `allow`, или
`CameraApi.setCameraAllowed(player, false)` из плагина. Камера выключается, фото не делаются.
Эти правила соблюдает мод игрока: они останавливают обычных игроков, но не изменённый клиент.

Игрокам: `/vrcamphotos` показывает ваши прикреплённые фото по страницам, с кнопкой снять каждое; клик по
координатам подставляет команду, чтобы туда попасть. Список предлагается и при достижении лимита.

Команды: `/vrcamsync stats`, `/vrcamsync purge <игрок>`, `/vrcamsync purgenear <блоки>`, `/vrcamsync reload`.

Что защищает сервер и других игроков:

- Каждую картинку сервер распаковывает и упаковывает заново. Ни один клиент не получает байты, присланные другим
  клиентом, — только обычный JPEG, сделанный сервером. Размер в пикселях проверяется до распаковки.
- Листок должен быть в пределах досягаемости игрока, на существующем блоке. Его размер берётся из картинки,
  а не из того, что сообщил клиент.
- Клиент может слать 10 сообщений в секунду. Того, кто продолжает флудить, сервер минуту не слушает.
- Картинки выдаются только для листков, о которых клиенту сообщили.
- Клиент так же проверяет всё, что присылает сервер, и принимает только картинки, которые сам запросил.

Чего это не делает: не оценивает, что на картинке. Игрок может закрепить любой скриншот игры. Для этого есть
команды выше, лимиты и `showOthersPhotos`.

## Без VR

На ПК Vivecraft необязателен. Режиссёр, следование и свободные камеры работают без шлема. Нажмите `F8`, чтобы
переключить режим: Выкл → Режиссёр → Следование → Свободная камера. Можно использовать `/vrcam screen
<режим>`. `F9` меняет план, `F10` удерживает его. Физика и жесты рук доступны только в VR.

**Отдельное окно для OBS.** `/vrcam screen window` открывает окно VRCamera, а в Minecraft остаётся ваш обычный
вид. В OBS добавьте «Захват окна». `/vrcam screen here` возвращает картинку камеры в окно игры.
Переключить вывод можно и в меню паузы или настройках.

- Работает на Minecraft 26.2 и 26.3 с OpenGL. Шейдеры не поддерживаются.
- Второй вид снижает FPS. `outputFps` ограничивает частоту кадров камеры (по умолчанию 60); снизьте её, чтобы уменьшить
  нагрузку.
- Разрешение рендера зависит от окна Minecraft, а форма кадра и размер вывода — от окна камеры.
  Для полноценной записи в 1080p увеличьте оба окна. Узкое высокое окно камеры даёт вертикальный кадр.
- `F11` в окне камеры включает полноэкранный режим без рамки. Монитор, размер и положение окна сохраняются.
  `/vrcam screen resetwindow` возвращает его на монитор игры, если оно оказалось вне досягаемости.
  `/vrcam screen size 2560 1440` делает картинку и окно ровно такого размера, даже на мониторе поменьше:
  программа записи получает столько пикселей, сколько их в окне. `/vrcam screen size auto` возвращает как было.
- Закрытие окна камеры или выход из мира выключает камеру ПК.
- Камера продолжает рендериться, когда Minecraft свёрнут или не в фокусе, в том числе с Dynamic FPS.
- Записываете оба окна? Звук игры идёт с обоих. Выключите захват звука у одного из них в программе записи,
  иначе звук задвоится.
- Открытое меню показывается перед персонажем на экране, который режиссёр снимает через плечо.
  `menuSize` задаёт размер экрана, `menuShotChat` включает чат. В тесноте камера может показать ваш вид от первого лица
  вместе с HUD.

**Двигать камеру.** Нажмите в её окне, чтобы взять управление; вернитесь в Minecraft, чтобы отпустить.
В самой игре можно нажать `G` или использовать `/vrcam screen steer`. Клавиши движения двигают камеру,
прыжок и приседание меняют высоту, колесо — зум. Режиссёр сохраняет ваш ракурс на `manualHoldSeconds`,
следование — до следующего изменения.

При отдельном окне можно навести прицел на модель камеры и зажать ПКМ. Камера плавно следует за взглядом,
колесо меняет расстояние до неё. Отпустите, чтобы поставить, или резко поверните взгляд при отпускании, чтобы
бросить (`throwPower`). Пока вы целитесь в камеру или держите её, ПКМ занят камерой.
`R` разворачивает камеру в руках от вас, чтобы показать то, на что вы смотрите. Ещё раз — обратно; когда
отпускаете, она всегда поворачивается к вам.

**Свободные камеры.** Остаются на месте и смотрят туда, куда вы их направили. До 26 камер с именами A–Z
сохраняются отдельно для каждого мира и измерения. При включении режима выбирается камера в пределах
64 блоков; если рядом нет ни одной, новая появляется у ваших глаз.

| Действие                              | Управление                                                   |
|---------------------------------------|--------------------------------------------------------------|
| Добавить камеру                       | `N`, `/cam add` или повторно `/vrcam screen free`            |
| Переключиться на камеру               | ЛКМ по её модели, `/cam B` или `1`–`9` для A–I в окне камеры |
| Следующая камера в пределах 64 блоков | `F7` или `/cam next`                                         |
| Плавный пролёт к следующей            | `/cam fly` или неназначенная клавиша пролёта                 |
| Вернуть активную камеру к глазам      | неназначенная клавиша вызова камеры                          |
| Удалить все сохранённые камеры мира   | `/cam clear` или `/vrcam screen clear`                       |

Берите и ставьте свободные камеры с помощью ПКМ. Отпустите камеру вплотную к мобу, лодке, вагонетке или другому игроку —
она закрепится на нём и будет ехать и поворачиваться вместе с ним, пока вы снова её не возьмёте или не полетите ею.
Брошенная камера плавно летит и замедляется; пролетев 48
блоков, удаляется, если она не последняя. `cameraLabelDistance` задаёт видимость подписей; 0 скрывает их.

При управлении свободной камерой клавиши движения перемещают её, спринт ускоряет, мышь поворачивает. `Esc`
освобождает мышь в окне камеры; щелчок захватывает её снова. Клавиши мода работают в обоих окнах. `H` в окне
камеры переключает направляющие: трети, золотое сечение, золотая спираль, половины, кадр 9:16, безопасные зоны 90%/80% и
выключение. Они видны при управлении и исчезают, когда вы отпускаете камеру.

**Наборы камер.** Набор — отдельная группа свободных камер для того же места. Меню паузы → «Свободные камеры»:
переключить набор, создать или удалить, скопировать набор в буфер и вставить присланный другом. То же делают
`/cam set`, `/cam export` и `/cam import <имя>`. Неназначенная клавиша перебирает наборы по очереди.

**Умное переключение.** Если свободных камер несколько, посмотрите на одну из них ненадолго, чтобы включить её.
Настройки: `freeAutoSwitch`, `freeAutoSwitchAngle` и `freeAutoSwitchSeconds`. Выбранная вручную камера
остаётся активной, пока вы не посмотрите на другую.

**Снимать друга.** `/cam follow Имя` переключает режиссёра и следование на этого игрока; `/cam follow`
возвращает съёмку к вам. `/cam with Имя` добавляет планы с вами вдвоём; `/cam with` убирает напарника.
Имена сохраняются в `filmPlayer` и `filmWith`. Свободные камеры сохраняют свой ракурс.

**Фото и мультиплеер.** `F6` снимает активную камеру, а при выключенных камерах — ваш вид.
Листок выезжает из активной камеры; при выключенных камерах он несколько секунд висит перед вами и падает.
Наведитесь на фото и зажмите ПКМ, чтобы взять: колесо — ближе или дальше, `R` — повернуть на четверть оборота.
Поднесите к блоку и отпустите, чтобы прикрепить; отпустите в воздухе — упадёт. У ваших лежащих фото есть значок
с расстоянием. Задержите взгляд на фото на полсекунды — оно крупно появится сбоку экрана с расстояния до 2 блоков
(`photoPreview`, `photoPreviewSeconds`, `photoPreviewDistance`); в картинку
камеры оно не попадает. На Windows снимок также попадает в буфер обмена (`photoClipboard`).
На сервере с плагином другие видят вашу активную камеру в пределах 48 блоков от вас, с учётом серверной
дальности показа. `shareCamera` выключает передачу; `othersCameras` ограничивает показ чужих камер (по умолчанию 3, 0
скрывает все).

**Хромакей.** `/vrcam chroma` снимает существ на одноцветном фоне (`chromaColor`, по умолчанию `#00B140`).
Кнопка в меню паузы переключает зелёный, красный, синий, ваш цвет и выключение. Освещение — как днём;
мир, погода, частицы, блок-сущности, виньетка и тени существ скрыты. `chromaDistance` задаёт дальность
(по умолчанию 32 блока, 0 — без ограничения). Меняется только картинка камеры, ваш вид остаётся обычным.
Шейдеры и графика Fabulous не поддерживаются.

## Режиссёр вручную

Играете от первого лица и сами переключаетесь на камеру, план за планом, как режиссёр трансляции.

1. Настройки → **Без VR** → куда идёт картинка: **окно игры**.
2. Настройки → **Режиссёр** → **Режиссёр: планы только вручную**: включить.
3. `F4` — мой вид ↔ камера. `F9` — следующий план.

С отдельным окном камеры вместо окна игры всё так же: `F4` показывает в окне камеры ваш вид от первого лица и
снова камеру.

Режиссёр после этого сам планы не меняет. Сменит только план, с которого камера вас не видит.

Сразу на нужный план, без перебора: назначьте в «Управлении» клавиши **План: из-за плеча / спереди / облёт /
пролёт мимо** или введите `/cam shot front`. Все планы подсказываются после `/cam shot `.

| Команда           | Что делает                                       |
|-------------------|--------------------------------------------------|
| `/cam toggle`     | мой вид ↔ камера                                 |
| `/cam shot`       | следующий план                                   |
| `/cam shot <имя>` | этот план; режиссёр включится, если был выключен |
| `/cam manual`     | ручной режим вкл/выкл                            |

Команды может отправлять за вас программа для стримов вроде Streamer.bot.

## Аватары Figura

С модом [NoFigura](https://modrinth.com/mod/nofigura) глаза вашего аватара могут смотреть в ПК-камеру: 2,5 секунды после
переключения на
другую свободную камеру и время от времени, пока камера ближе 8 блоков и перед лицом.

Глаза — часть аватара, двигает их его скрипт. Мод только говорит, куда смотреть, через глобал `vrcamera`:

1. Поставьте [NoFigura](https://modrinth.com/mod/nofigura) рядом с VRCamera.
2. Добавьте в скрипт аватара один из двух кусков ниже.
3. Перезагрузите аватар и включите камеру.

С библиотекой [Gaze](https://github.com/Bitslayn/FOX-Gaze), где `tracking` — то, что вернул `gaze:newGaze()`:

```lua
events.tick:register(function()
  local lens = vrcamera and vrcamera:getLookTarget()
  if lens then
    tracking:setTargetOverride(lens)
  end
end, "VRCameraEyes")
```

Если глаза двигает ваш код, подставьте свой путь к ним:

```lua
function events.render()
  local look = vrcamera and vrcamera:getLookOffset()
  local x = look and math.clamp(look.x / 60, -1, 1) or 0
  local y = look and math.clamp(look.y / 60, -1, 1) or 0
  models.model.Head.Eyes:setPos(-x, y, 0)
end
```

`getLookTarget()` — позиция объектива, `getLookOffset()` — градусы вправо и вверх от направления головы. Обе
возвращают `nil`, когда смотреть не на что. Ещё есть `isFilming()` и `getCameraPos()`.

Отвечает только вашему аватару и только в вашей игре: для записи этого хватает. Чтобы движение глаз видели
другие игроки, передавайте его через ping. Камера в руке в VR не поддерживается.

## Метка, значок и отладочный оверлей

**Метка.** Модель камеры Vivecraft с экранчиком показывает камеру в шлеме. В записи её нет. `marker`
выбирает `"model"`, `"dot"` (красная точка с подписью `REC` и названием плана) или `"none"`.

**Значок камеры.** Значок с расстоянием в блоках, как путевая точка: виден сквозь стены, одного размера на любом
расстоянии, в обоих глазах. Когда камера вне поля зрения, значок прилипает к краю обзора с её стороны. Его нет,
когда камера ближе 1.2 блока и в плане от первого лица. В запись не попадает. `indicator` включает его,
`indicatorSize` задаёт размер.

**Отладочный оверлей.** Показывает на HUD, что делает камера.

| Строка                      | Что значит                                                                              |
|-----------------------------|-----------------------------------------------------------------------------------------|
| `VRCamera DIRECTOR`         | режим; `(waiting for VR)` — VR не работает; `(parked 12s)` — ждёт, пока её возьмут      |
| `shot: ORBIT left 3.2/9.5s` | план, сторона, сколько идёт и сколько продлится; `HOLD` — удержание                     |
| `why: time, blend`          | почему выбран план и как камера к нему перешла                                          |
| `context: RUN tight`        | ситуация; `tight` — тесно; `event FALL` — событие                                       |
| `blocked: 0.4s`             | сколько секунд стены прижимают камеру                                                   |
| `arm: 100%`                 | какая доля дистанции у камеры есть; `(looking past)` — смотрит мимо тонкого препятствия |
| `fov`, `speed`, `scale`     | угол обзора, ваша скорость, ваш размер                                                  |
| `target: Zombie`            | цель в бою                                                                              |

Причины в строке `why`:

| Причина                    | Когда                                                         |
|----------------------------|---------------------------------------------------------------|
| `start`                    | первый план после включения или возврата VR                   |
| `time`                     | вышло время                                                   |
| `blocked`                  | стены прижали камеру                                          |
| `finished`                 | план закончился сам: `flyby` — вы ушли, `duel` — цель пропала |
| `now COMBAT`               | началось новое                                                |
| `unfit for SWIM`           | план не подходит новой ситуации                               |
| `key`                      | нажата «Следующий план»                                       |
| `teleport`                 | телепорт во время `flyby`                                     |
| `event FALL`, `event over` | событие началось или закончилось                              |
| `manual`                   | постановка рукой или выбран свой ракурс                       |

**Темп.** Три готовых набора значений: сколько длятся планы и насколько охотно двигается камера. Выбирается
в настройках («Темп») или командой `/vrcam pace <имя>`:

| Темп      | Для чего                                                         | Планы                        |
|-----------|------------------------------------------------------------------|------------------------------|
| `default` | YouTube, длинные видео: легко следить, длинные куски для монтажа | 5–18 с, минимум 4 с до смены |
| `faster`  | TikTok, шортсы: смен больше, материала для монтажа меньше        | 4–16 с, минимум 3 с          |

Выбор темпа записывает `minShotTime`, `orbitSpeed`, `manualHoldSeconds`, `turnLag`, `turnDeadzone`,
`handStabilize` и `minDuration`/`maxDuration` планов и затирает то, что вы там выставили руками. После этого
каждое значение снова можно менять отдельно.

### Поля плана

В `shots` по записи на план, в `presets` — ракурсы, поставленные рукой.

| Поле                         | Значение                                                                            |
|------------------------------|-------------------------------------------------------------------------------------|
| `enabled`                    | использовать ли план                                                                |
| `weight`                     | относительный шанс                                                                  |
| `azimuth`                    | градусы вокруг игрока: 0 — спереди, 180 — сзади. Лево или право выбирается случайно |
| `elevation`                  | градусы над горизонтом                                                              |
| `distance`                   | блоки, для игрока обычного размера                                                  |
| `fov`                        | угол обзора                                                                         |
| `minDuration`, `maxDuration` | длительность плана в секундах                                                       |

Исключения:

- `flyby`: `distance` — насколько далеко впереди встаёт камера, углы не используются.
- `duel`: `azimuth` отсчитывается от направления на противника.
- свои ракурсы: `azimuth` со знаком, от −180 до 180, не зеркалится.

### Что крутить

| Что видите                              | Что менять                                             |
|-----------------------------------------|--------------------------------------------------------|
| Камеру мотает при поворотах головы      | поднять `turnDeadzone` и `turnLag`                     |
| Камера вялая                            | уменьшить `positionLag`                                |
| Слишком частые смены в тесноте          | поднять `occlusionCutTime`, уменьшить `occlusionRatio` |
| Камера дёргается у деревьев и столбов   | поднять `softOcclusionTime`                            |
| Вы пропадаете за деревьями              | уменьшить `softOcclusionTime` или поставить 0          |
| Планы слишком короткие или длинные      | `minDuration`, `maxDuration` у плана                   |
| Нужны только склейки или только пролёты | `transition`                                           |
| Вы не по центру при беге                | `leadRoom: 0`                                          |
| Камера в руке трясётся                  | поднять `handStabilize`, уменьшить `physicsShake`      |
| Рука ловит камеру случайно              | `pullAllModes: false`                                  |
| План не нравится                        | `enabled: false` у него                                |

## Шлем снят, VR выключился

Если в Vivecraft включён **Hotswitching**, снятый шлем переключает игру в режим без VR. VR выключается и
тогда, когда его отключили вручную или случилась ошибка рендера.

- Окно игры показывает обычный вид от первого лица. Так устроен Vivecraft: без VR ручной камеры нет.
- Мод возвращает настройки Vivecraft и ждёт. Режим сохраняется.
- Когда VR возвращается, камера включается сама и начинает с нового плана.
- `F8` при выключенном VR выключает камеру.

Для стрима Hotswitching лучше выключить. Тогда игра остаётся в VR, и камера продолжает снимать.

## Если что-то не так

| Симптом                               | Причина и что делать                                                                               |
|---------------------------------------|----------------------------------------------------------------------------------------------------|
| «VR не запущен»                       | VR в Vivecraft выключен или шлем не подхвачен                                                      |
| «недоступна в сидячем режиме»         | переключить Vivecraft в стоячий режим                                                              |
| Окно игры чёрное                      | Desktop Mirror стоит в OFF                                                                         |
| Персонажа нет в кадре камеры          | включите «Показ Модели Игрока» в Vivecraft: VR Settings → «Настройки Модели Игрока»                |
| В окне вид от первого лица            | `forceMirror` выключен, или VR сейчас не работает                                                  |
| В шлеме нет модели камеры             | проверить `marker`: `"model"` — камера Vivecraft, `"dot"` — красная точка                          |
| Камера за спиной в плане `front`      | ошибка мода, сообщите о ней                                                                        |
| Камеру не достать                     | «Камеру ко мне» или притянуть                                                                      |
| «внутренняя ошибка, камера выключена» | мод поймал свою ошибку и остановился, чтобы вас не выкинуло из VR. Подробности в `logs/latest.log` |
| Нет кнопки «Настройки»                | не установлен Cloth Config                                                                         |
| Клавиши не работают                   | окно игры не в фокусе или открыто меню                                                             |

## Известные ограничения

- Мод использует внутренние классы Vivecraft, а не только публичный API. Обновление Vivecraft может его сломать.
- Поза камеры отстаёт на кадр: Vivecraft читает её до запуска трекеров.
- Пока камера включена, мод меняет у Vivecraft угол обзора камеры и вывод в окно, а при выключении возвращает.
  Если Vivecraft сохранит конфиг в это время и игра упадёт, изменённые значения останутся в его файле.
- Пока вы смотрите на камеру и наводите на неё руку, кнопка взаимодействия этой руки занята притягиванием.
- Притянутая камера летит сквозь стены.
- Тело погибшего исчезает примерно через секунду, а план смерти длится до возрождения.
