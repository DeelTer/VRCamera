# VRCamera

[English version](README.md)

Аддон для [Vivecraft](https://modrinth.com/mod/vivecraft). Он сам двигает ручную камеру Vivecraft и снимает игрока
от третьего лица. Сделан для стримов и записи через OBS.

Четыре режима:

- **Режиссёр** выбирает ракурсы и переключает их, как кинематографическая камера в GTA.
- **Следование** держит камеру там, куда вы поставили её рукой, относительно игрока.
- **Физика** превращает камеру в предмет: её носят, роняют, бросают и пинают.
- **Выкл** — мод камеру Vivecraft не трогает.

Камера не залезает в блоки, держит игрока в кадре и целится в середину тела. Все дистанции умножаются на атрибут
`scale`.

Как мод устроен внутри: [ARCHITECTURE.md](ARCHITECTURE.md) (на английском).

## Требования

| | |
|---|---|
| Minecraft | 26.2 или 26.3, для каждой версии свой jar |
| Загрузчик | Fabric Loader 0.19.5+ и Fabric API |
| Vivecraft | 1.3.13+ |
| Java | 25 |
| Cloth Config | необязательно: экран настроек в игре |
| Mod Menu | необязательно: кнопка настроек в списке модов |

Только клиент, на сервер ставить не нужно. Только стоячий VR: в сидячем режиме Vivecraft отключает ручную камеру.

Переведён на английский, русский, украинский, немецкий, французский, испанский, бразильский португальский
и упрощённый китайский.

## Установка

В папку `mods` положить:

- `vrcamera-1.0.0+<версия Minecraft>.jar`
- Vivecraft для той же версии Minecraft (Fabric)
- Fabric API
- Cloth Config и Mod Menu — по желанию

Jar одной версии Minecraft на другой не запустится.

### Сборка

```bash
./gradlew build
```

```bash
./gradlew build -Pmc=26.3
```

Первая команда собирает под 26.2, вторая — под 26.3. Jar-файлы появляются в `build/libs/`.

Все версии сразу:

```bash
./gradlew buildAll
```

Версии Minecraft и зависимостей лежат в `versions/<версия>.properties`. Чтобы поддержать ещё одну версию Minecraft,
добавьте туда файл. Версию по умолчанию, её же берёт IDE, задаёт поле `mc` в `gradle.properties`.

## Быстрый старт

1. Запустить игру, включить VR, зайти в мир.
2. Нажать `F8` или кнопку **VR-камера** в меню паузы. Режимы идут по кругу: Выкл → Режиссёр → Следование → Физика.
3. В OBS захватить окно Minecraft.

Пока камера включена, окно игры показывает картинку от третьего лица. В шлеме на месте камеры видна красная точка.

## Настройка Vivecraft и OBS

| Настройка Vivecraft | Значение | Зачем |
|---|---|---|
| Режим игры | Standing | в сидячем нет ручной камеры |
| Desktop Mirror | любой, кроме OFF | при OFF Vivecraft ничего не рисует в окно |
| Camera Resolution | 1.0 даёт 1920×1080 | выше — дороже по FPS |
| GUI On Mirror | OFF для стрима | иначе HUD попадёт в запись |
| Hotswitching | OFF для стрима | иначе при снятом шлеме окно переключится на вид от первого лица |
| Camera as Desktop Mirror | не трогать | мод включает её на время работы и возвращает обратно |

OBS:

1. Сделать окно Minecraft 16:9, например 1920×1080. При другом соотношении будут чёрные полосы.
2. Добавить источник «Захват игры» или «Захват окна».
3. Окно не сворачивать.

Камера — ещё один полный рендер мира сверх двух глаз. FPS падает так же, как при обычной включённой камере
Vivecraft.

Клавиши — обычные привязки Minecraft. Их можно переназначить в настройках управления или привязать к кнопкам
контроллеров в SteamVR. Они работают, когда окно игры в фокусе и меню закрыто, так что камерой может управлять
человек за компьютером, пока игрок в шлеме.

### Команды

`/vrcam` делает то же самое, с подсказками по Tab. Команда выполняется на клиенте и прав не требует.

| Команда | Что делает |
|---|---|
| `/vrcam`, `/vrcam status` | пишет то же, что показывает отладочный оверлей |
| `/vrcam off`, `director`, `follow`, `physics` | включает этот режим |
| `/vrcam mode` | следующий режим |
| `/vrcam next` | следующий план |
| `/vrcam hold` | удерживает или отпускает текущий план |
| `/vrcam shot <имя>` | показывает план: `shoulder`, `front`, `orbit`, `flyby`, `crane`, `low`, `hands`, `duel`, `death`, `fall`, `pov`, `menu`, `custom`. Включает режиссёра, если нужно |
| `/vrcam summon` | камеру ко мне |
| `/vrcam preset next`, `new`, `delete` | свои ракурсы |
| `/vrcam preset <номер>` | выбирает свой ракурс, считая с 1 |
| `/vrcam debug` | отладочный оверлей |
| `/vrcam settings` | экран настроек, нужен Cloth Config |
| `/vrcam reload` | перечитывает файл настроек |

`/vrcam shot` показывает план, даже если он выключен или не подходит ситуации. План длится как обычно, потом
режиссёр продолжает сам. Чтобы план остался, выполните после него `/vrcam hold`.

В шлеме удобнее положить команды в быстрые команды Vivecraft (Quick Commands). Они появятся под кнопкой
**Commands** в меню паузы, и каждую можно привязать к кнопке контроллера в SteamVR.

## Камера в руках

Всё это работает в любом режиме.

**Взять и поставить.** Поднесите руку к красной точке и зажмите кнопку взаимодействия, как с обычной камерой
Vivecraft. Когда отпустите:

- в «Следовании» камера остаётся в этой точке относительно вас;
- в «Режиссёре» держит этот ракурс `manualHoldSeconds` секунд, потом режиссёр продолжает сам;
- в «Физике» падает.

Камера запоминает только позицию. Смотрит она всегда на игрока.

**Бросить.** Замахнитесь и отпустите. Камера улетит в сторону броска и останется там, стены её останавливают.
Чем быстрее замах, тем дальше. Движение медленнее 2.5 блока в секунду броском не считается. Дальность задаёт
`throwPower`, 0 выключает бросок. Обычную камеру Vivecraft при выключенном моде тоже можно бросать.

**Притянуть издалека.** Посмотрите на камеру и наведите на неё руку: контроллер коротко вздрогнет. Зажмите кнопку
взаимодействия. Вибрация нарастает, и через `pullSeconds` секунд (по умолчанию 1.25) камера прилетает в руку.
Она остаётся в руке, пока кнопка зажата. Рука берёт её за бок и не закрывает объектив. Работает на расстоянии
от 1.5 до 64 блоков.

В «Режиссёре» и «Следовании» камера часто висит перед вами, и рука может поймать её случайно. Если это мешает,
выключите `pullAllModes`: притягивание останется только в «Физике».

**Камеру ко мне.** Следящая камера отступает, когда к ней идёшь. Эта кнопка ставит её перед лицом на расстоянии
вытянутой руки на 20 секунд.

**Стабилизация.** Рука дрожит и подёргивается, когда другой рукой ломаешь блок. Мод это сглаживает, а намеренные
движения пропускает. Силу задаёт `handStabilize`, 0 выключает.

### Свои ракурсы

Ракурсов, поставленных рукой, может быть несколько. Постановка рукой всегда записывается в активный.

- **Новый ракурс** копирует активный и делает копию активной. После этого поставьте камеру.
- **Следующий свой ракурс** переключает их по кругу, камера перелетает.
- **Удалить ракурс** удаляет активный. Последний остаётся.

Обычный порядок: «Новый ракурс» → «Камеру ко мне» → взять, поставить, отпустить.

## Режим «Физика»

Для «найденной плёнки» и хоррора: камера — предмет, который держат в руке.

- Держите её, и она снимает туда, куда направлена рука. В шлеме она выглядит как камера Vivecraft с экранчиком.
- Отпустите, и она падает, отскакивает и кувыркается. Скорость руки сохраняется, так что её можно бросить.
- Пока камера успокаивается, она доворачивается объективом к вам и остаётся лежать с завалом. Иначе она почти
  всегда снимала бы землю или небо. Насколько доворачивается, задаёт `physicsAim`: 0 — лежит как упала, 1 — смотрит
  прямо на вас.
- Остановившись, она за вами больше не следит. Отойдите и войдите в кадр.
- От мобов, лодок и вагонеток она отскакивает как от блоков. Упав на лодку или вагонетку, едет вместе с ней.
  Её можно уронить в лодке, в которой сидишь.
- Лежащую камеру отбрасывает тот, кто в неё вошёл: вы, моб, лодка. Медленный шаг её не трогает.
- Руки и ноги бьют по брошенной камере, в воздухе и на земле: её можно пнуть или набивать как волейбольный мяч.
  Камера, упавшая на неподвижную руку, от неё отскакивает. Для ног нужен трекинг всего тела. Силу задаёт
  `kickPower`, 0 выключает.
- Камера в руке покачивается от дыхания, сильнее — от шагов, и вздрагивает, когда вас бьют. Силу задаёт
  `physicsShake`.
- Когда вы умираете, камера выпадает из руки и доворачивается так, чтобы в кадре были тело и убийца.
- При ударе дёргается зум, слышен звук блока и летит его пыль. Пыль появляется только позади объектива: вы её
  видите, камера — нет.
- В воде и лаве она тонет медленно. Если блок под ней сломали, падает дальше.
- Дальше 40 блоков она возвращается к вам: Vivecraft прячет слишком далёкую камеру.
- При включении режима камера появляется перед лицом на 20 секунд. Не взяли — падает.

Режиссёр, свои ракурсы и события в этом режиме не работают.

## Планы

| Ключ | Что делает | Когда выбирается чаще |
|---|---|---|
| `shoulder` | сзади, из-за плеча | движение, полёт, тесные места |
| `front` | спереди, пятится; наезжает, пока вы стоите | простой, ходьба |
| `orbit` | медленно облетает игрока | простой, бой |
| `flyby` | стоит впереди по пути и провожает поворотом, с зумом | бег, полёт, езда |
| `crane` | поднимается высоко позади игрока | открытые места, полёт |
| `low` | от земли, снизу вверх | бой, бег |
| `hands` | крупный план рук | копание, простой |
| `duel` | из-за плеча на противника, оба в кадре | бой с целью |
| `death` | облетает погибшего и отъезжает | только при смерти |
| `fall` | почти отвесно сверху | только при долгом падении |
| `pov` | от первого лица: прямо перед лицом | там, где больше ни для чего нет места |
| `menu` | близко из-за плеча на открытое меню | пока открыто меню |
| свой | ракурс, поставленный рукой | режим «Следование» |

## Как работает режиссёр

**Ситуация.** Режиссёр знает, чем вы заняты: стоите, идёте, бежите, летите на элитрах, едете верхом, плывёте,
дерётесь, копаете. Ещё он знает, тесно ли вокруг. От этого зависят шансы планов и дистанции: в тесноте ближе,
в полёте дальше.

**Смена плана.** План меняется, когда:

- вышло его время;
- стены прижали камеру слишком близко;
- началось новое: бой, полёт, езда, плавание или больше секунды копания;
- нажата «Следующий план».

Смена — это либо склейка, когда камера сразу оказывается в новой точке, либо пролёт, когда она облетает игрока.
Два похожих плана подряд режиссёр не ставит. Ещё камера старается оставаться по одну сторону от линии, вдоль
которой вы движетесь: иначе в одном плане вы бежите вправо, а в следующем — влево.

При телепорте камера прыгает вместе с вами и сохраняет ракурс. Заменяется только `flyby`, потому что он стоит
на месте.

Удержание (`F10`) останавливает смены планов и события, пока вы его не снимете.

**Бой.** Бой начинается, когда вы ударили живое существо, в том числе взмахом контроллера, или оно ранило вас.
Оно становится целью. Урон от падения и огня не считается. Цель сбрасывается через 5 секунд без боя, при её
смерти или когда она далеко.

**События.**

- **Смерть:** `death` до возрождения. Если вас кто-то убил, убийца остаётся в кадре.
- **Долгое падение:** `fall` включается склейкой, когда под вами больше 6 блоков пустоты, и держится ещё секунду
  после приземления.
- **Взлёт на элитрах:** у `flyby` повышенный шанс на следующую смену.
- **Открытое меню:** `menu`, пока открыты инвентарь, сундук, меню паузы, настройки или чат. Vivecraft показывает
  меню в мире, поэтому в кадре и меню, и игрок. Камера встаёт за то плечо, где больше места. Если места нет
  ни за одним, включается вид от первого лица. `menuShotChat` отключает это для чата.

Если плечо закрывает меню, уменьшите у плана `menu` угол вокруг (`azimuth`): 180 — точно за спиной, меньше —
сильнее сбоку. По умолчанию 138.

**Запас по ходу.** В движении камера целится чуть впереди вас, чтобы в кадре было место по ходу. `leadRoom: 0`
возвращает прицел в середину тела.

## Как камера избегает блоков

- От середины тела к нужной точке идут восемь лучей. Если на пути блок, камера встаёт перед ним.
- Придвигается она сразу, отодвигается плавно.
- Тонкое препятствие — ствол, столб — камера игнорирует до `softOcclusionTime` секунд, если сама стоит в свободном
  месте. В блок она не заходит никогда.
- В лаву и рыхлый снег она не встаёт, пока вы сами не в них.
- Если камера прижата дольше `occlusionCutTime`, режиссёр меняет ракурс.

Обход камера не ищет. Режиссёр выбирает ракурс, с которого вас видно.

Когда места нет ни для одного ракурса, например в туннеле в один блок, включается `pov`. Камера стоит в трети
блока перед лицом, а не в глазах: там она видела бы голову модели игрока изнутри. Насколько впереди, задаёт
`distance` этого плана.

## Метка, значок и отладочный оверлей

**Метка.** Красная точка с подписью `REC` и названием плана показывает камеру в шлеме. В записи её нет. `marker`
выбирает `"dot"`, `"model"` (модель камеры Vivecraft) или `"none"`.

**Значок камеры.** Значок с расстоянием в блоках, как путевая точка: виден сквозь стены, одного размера на любом
расстоянии, в обоих глазах. Когда камера вне поля зрения, значок прилипает к краю обзора с её стороны. Его нет,
когда камера ближе 1.2 блока и в плане от первого лица. В запись не попадает. `indicator` включает его,
`indicatorSize` задаёт размер.

**Отладочный оверлей.** Показывает на HUD, что делает камера.

| Строка | Что значит |
|---|---|
| `VRCamera DIRECTOR` | режим; `(waiting for VR)` — VR не работает; `(parked 12s)` — ждёт, пока её возьмут |
| `shot: ORBIT left 3.2/9.5s` | план, сторона, сколько идёт и сколько продлится; `HOLD` — удержание |
| `why: time, blend` | почему выбран план и как камера к нему перешла |
| `context: RUN tight` | ситуация; `tight` — тесно; `event FALL` — событие |
| `blocked: 0.4s` | сколько секунд стены прижимают камеру |
| `arm: 100%` | какая доля дистанции у камеры есть; `(looking past)` — смотрит мимо тонкого препятствия |
| `fov`, `speed`, `scale` | угол обзора, ваша скорость, ваш размер |
| `target: Zombie` | цель в бою |

Причины в строке `why`:

| Причина | Когда |
|---|---|
| `start` | первый план после включения или возврата VR |
| `time` | вышло время |
| `blocked` | стены прижали камеру |
| `finished` | план закончился сам: `flyby` — вы ушли, `duel` — цель пропала |
| `now COMBAT` | началось новое |
| `unfit for SWIM` | план не подходит новой ситуации |
| `key` | нажата «Следующий план» |
| `teleport` | телепорт во время `flyby` |
| `event FALL`, `event over` | событие началось или закончилось |
| `manual` | постановка рукой или выбран свой ракурс |

## Настройки

**В игре.** Нужен Cloth Config. Экран открывается с экрана «VR-камера...» или из списка модов, если стоит
Mod Menu. Все числа — слайдеры, в VR ничего не нужно набирать. Изменения применяются по «Сохранить».

**Файл.** `config/vrcamera.json`, создаётся при первом запуске. Перечитывается при включении камеры из «Выкл»
и командой `/vrcam reload`.

### Общее

| Поле | По умолчанию | Значение |
|---|---|---|
| `forceMirror` | `true` | показывать картинку камеры в окне игры, пока камера включена |
| `marker` | `"dot"` | `"dot"`, `"model"` или `"none"` |
| `markerLabel` | `true` | название плана рядом с точкой |
| `markerSize` | `14` | размер точки |
| `indicator` | `true` | значок камеры с расстоянием |
| `indicatorSize` | `1.0` | размер значка |
| `throwPower` | `1.0` | множитель дальности броска, 0 — без броска |
| `handStabilize` | `0.5` | стабилизация камеры в руке, 0 — выключена, 1 — максимум |
| `pullSeconds` | `1.25` | сколько секунд держать кнопку, чтобы притянуть камеру, 0 — без притягивания |
| `pullAllModes` | `true` | `false` — притягивание только в «Физике» |
| `physicsAim` | `0.75` | «Физика»: насколько упавшая камера доворачивается к игроку, от 0 до 1 |
| `physicsShake` | `1.0` | «Физика»: покачивание камеры в руке, 0 — выключено |
| `kickPower` | `1.0` | «Физика»: сила удара руками и ногами по брошенной камере, 0 — проходят сквозь неё |
| `menuShotChat` | `true` | план `menu` и для чата |
| `debugOverlay` | `false` | отладочный оверлей на HUD |

### Движение

| Поле | По умолчанию | Значение |
|---|---|---|
| `aimHeight` | `0.6` | куда целиться: 0 — ноги, 1 — голова |
| `positionLag` | `0.35` | секунд, за которые камера догоняет нужную позицию |
| `lookLag` | `0.12` | секунд, за которые прицел догоняет игрока |
| `turnLag` | `0.9` | секунд на облёт, когда игрок поворачивается |
| `turnDeadzone` | `12` | на сколько градусов можно повернуться, не сдвинув камеру |
| `speedFov` | `true` | шире угол обзора на большой скорости |
| `leadRoom` | `0.25` | на сколько секунд движения вперёд целится камера, 0 — выключено |
| `leadRoomMax` | `0.8` | предел этого смещения, в размерах игрока |

### Коллизии

| Поле | По умолчанию | Значение |
|---|---|---|
| `collisionRadius` | `0.15` | отступ камеры от стен, в блоках |

| `softOcclusionTime` | `0.35` | сколько секунд игнорировать тонкое препятствие, 0 — выключено |

### Режиссёр

| Поле | По умолчанию | Значение |
|---|---|---|
| `transition` | `"auto"` | `"auto"`, `"cut"` (только склейки) или `"blend"` (только пролёты) |
| `blendChance` | `0.6` | шанс пролёта при `"auto"` |
| `minShotTime` | `2.5` | минимум секунд до смены из-за новой ситуации |
| `manualHoldSeconds` | `20` | сколько режиссёр держит ракурс, поставленный рукой |
| `orbitSpeed` | `14` | скорость облёта, градусов в секунду |
| `events` | `true` | особые планы для смерти и падения |
| `activePreset` | `0` | номер активного своего ракурса, считая с 0 |
| `customInRotation` | `false` | свои ракурсы участвуют в ротации режиссёра |

### Поля плана

В `shots` по записи на план, в `presets` — ракурсы, поставленные рукой.

| Поле | Значение |
|---|---|
| `enabled` | использовать ли план |
| `weight` | относительный шанс |
| `azimuth` | градусы вокруг игрока: 0 — спереди, 180 — сзади. Лево или право выбирается случайно |
| `elevation` | градусы над горизонтом |
| `distance` | блоки, для игрока обычного размера |
| `fov` | угол обзора |
| `minDuration`, `maxDuration` | длительность плана в секундах |

Исключения:

- `flyby`: `distance` — насколько далеко впереди встаёт камера, углы не используются.
- `duel`: `azimuth` отсчитывается от направления на противника.
- свои ракурсы: `azimuth` со знаком, от −180 до 180, не зеркалится.

### Что крутить

| Что видите | Что менять |
|---|---|
| Камеру мотает при поворотах головы | поднять `turnDeadzone` и `turnLag` |
| Камера вялая | уменьшить `positionLag` |
| Слишком частые смены в тесноте | поднять `occlusionCutTime`, уменьшить `occlusionRatio` |
| Камера дёргается у деревьев и столбов | поднять `softOcclusionTime` |
| Вы пропадаете за деревьями | уменьшить `softOcclusionTime` или поставить 0 |
| Планы слишком короткие или длинные | `minDuration`, `maxDuration` у плана |
| Нужны только склейки или только пролёты | `transition` |
| Вы не по центру при беге | `leadRoom: 0` |
| Камера в руке трясётся | поднять `handStabilize`, уменьшить `physicsShake` |
| Рука ловит камеру случайно | `pullAllModes: false` |
| План не нравится | `enabled: false` у него |

## Шлем снят, VR выключился

Если в Vivecraft включён **Hotswitching**, снятый шлем переключает игру в режим без VR. VR выключается и тогда,
когда его отключили вручную или случилась ошибка рендера.

- Окно игры показывает обычный вид от первого лица. Так устроен Vivecraft: без VR ручной камеры нет.
- Мод возвращает настройки Vivecraft и ждёт. Режим сохраняется.
- Когда VR возвращается, камера включается сама и начинает с нового плана.
- `F8` при выключенном VR выключает камеру.

Для стрима Hotswitching лучше выключить. Тогда игра остаётся в VR, и камера продолжает снимать.

## Если что-то не так

| Симптом | Причина и что делать |
|---|---|
| «VR не запущен» | VR в Vivecraft выключен или шлем не подхвачен |
| «недоступна в сидячем режиме» | переключить Vivecraft в стоячий режим |
| Окно игры чёрное | Desktop Mirror стоит в OFF |
| В окне вид от первого лица | `forceMirror` выключен, или VR сейчас не работает |
| Нет красной точки | поставить `marker: "model"`, появится модель камеры Vivecraft |
| Камера за спиной в плане `front` | ошибка мода, сообщите о ней |
| Камеру не достать | «Камеру ко мне» или притянуть |
| «внутренняя ошибка, камера выключена» | мод поймал свою ошибку и остановился, чтобы вас не выкинуло из VR. Подробности в `logs/latest.log` |
| Нет кнопки «Настройки» | не установлен Cloth Config |
| Клавиши не работают | окно игры не в фокусе или открыто меню |

## Известные ограничения

- Мод использует внутренние классы Vivecraft, а не только публичный API. Обновление Vivecraft может его сломать.
- Поза камеры отстаёт на кадр: Vivecraft читает её до запуска трекеров.
- Пока камера включена, мод меняет у Vivecraft угол обзора камеры и вывод в окно, а при выключении возвращает.
  Если Vivecraft сохранит конфиг в это время и игра упадёт, изменённые значения останутся в его файле.
- Пока вы смотрите на камеру и наводите на неё руку, кнопка взаимодействия этой руки занята притягиванием.
- Притянутая камера летит сквозь стены.
- Тело погибшего исчезает примерно через секунду, а план смерти длится до возрождения.
- Автотестов нет.
