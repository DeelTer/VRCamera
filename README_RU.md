# VRCamera

[English version](README.md) · [Справочник](docs/GUIDE_RU.md)

Кинематографическая камера для стримов, записи и скриншотов Minecraft в VR и на ПК.
В VR мод управляет ручной камерой [Vivecraft](https://modrinth.com/mod/vivecraft), на ПК снимает через отдельное окно.
Для игры на ПК Vivecraft необязателен.

- **Режиссёр** сам выбирает ракурсы и переключает планы.
- **Следование** сохраняет ваш ракурс относительно игрока.
- **Свободная камера (ПК)** — до 26 сохранённых камер, плавные пролёты и переключение взглядом.
- **Физика (VR)** позволяет носить, ронять, бросать, пинать и закреплять камеру.

Режиссёр и следование держат игрока в кадре и не проходят сквозь блоки. На ПК можно снимать другого игрока или добавлять
друга в совместные планы.

## Установка

Поддерживаются **Minecraft 26.2 и 26.3**, для каждой версии свой jar. Нужны **Java 25**, **Fabric Loader** и **Fabric
API**. Положите подходящий jar VRCamera в `mods`.

Для VR установите Vivecraft для той же версии Minecraft и включите **стоячий режим**: в сидячем режиме ручная камера
отключена.
По желанию: **Cloth Config** добавляет настройки, **Mod Menu** — кнопку настроек в списке модов. Версии зависимостей
сборки указаны в [`versions/`](versions/).

Мод работает на клиенте. Серверный плагин нужен только для обмена фото и положением камер между игроками.

## Быстрый старт

**ПК:** зайдите в мир, выберите режим через `F8` и выполните `/vrcam screen window`, чтобы открыть отдельное окно
VRCamera. В OBS добавьте «Захват окна». `/vrcam screen here` возвращает картинку в окно Minecraft.

**VR:** включите VR, зайдите в мир и нажмите `F8` или кнопку **VR-камера** в меню паузы. В OBS захватите окно Minecraft.
Модель камеры видна в шлеме, но не попадает в запись.

`/vrcam chroma` включает хромакей. На ПК узкое высокое окно даёт вертикальный кадр; `F11` в окне камеры включает
полноэкранный режим.

## Настройка Vivecraft и OBS

Для VR проверьте настройки Vivecraft:

| Настройка                | Значение                                                                       |
|--------------------------|--------------------------------------------------------------------------------|
| Show Playermodel         | **ВКЛ** в VR Settings → Playermodel Settings, иначе персонажа не будет в кадре |
| Desktop Mirror           | Любой, кроме OFF                                                               |
| Camera Resolution        | 1.0 для 1920×1080; выше — дороже по FPS                                        |
| GUI On Mirror            | OFF, чтобы убрать HUD из записи                                                |
| Hotswitching             | OFF, чтобы съёмка не прерывалась при снятии шлема                              |
| Camera as Desktop Mirror | Мод меняет сам и возвращает при выключении                                     |

Для записи 16:9 выберите соответствующий размер окна, например 1920×1080. Камера рендерит ещё один вид мира и
увеличивает нагрузку на GPU. На ПК можно снизить `outputFps`; разрешение рендера зависит от размера окна Minecraft.

## Управление

| Действие                                         | Клавиша |
|--------------------------------------------------|---------|
| Переключить режим                                | `F8`    |
| Следующий план                                   | `F9`    |
| Удержать/отпустить план                          | `F10`   |
| Следующий свой ракурс или свободная камера рядом | `F7`    |
| Сделать фото                                     | `F6`    |
| Новый свой ракурс / свободная камера             | `N`     |
| Управлять камерой ПК                             | `G`     |
| Повернуть камеру или фото в руках                | `R`     |

Клавиши можно переназначить в Minecraft, а в VR — добавить в радиальное меню Vivecraft или привязать через SteamVR.
Клиентские команды имеют подсказки по Tab и не требуют прав на сервере. [Полный список](docs/GUIDE_RU.md#команды).

Команды свободных камер: `/cam add`, `/cam B`, `/cam next`, `/cam fly`, `/cam clear`.
`/cam follow Имя` снимает другого игрока, `/cam with Имя` добавляет напарника в кадр.

## Камера в руках

**VR:** зажмите кнопку взаимодействия рядом с камерой, чтобы взять её; отпустите, чтобы поставить или уронить. Взмахните
и отпустите, чтобы бросить. Для притягивания издалека посмотрите на камеру, наведите руку и зажмите взаимодействие после
вибрации контроллера.

**ПК, с отдельным окном:** наведитесь на камеру и зажмите ПКМ. Двигайте её взглядом, меняйте расстояние колесом и
отпустите, чтобы поставить. `R` разворачивает её от вас, чтобы показать то, на что вы смотрите; отпустите — она
повернётся обратно к вам. Щелчок в её окне или `G` передаёт управление клавишам движения.

**Фото на ПК:** наведитесь на фото и зажмите ПКМ, чтобы взять. Колесо — ближе или дальше, `R` — повернуть.
Поднесите к блоку и отпустите, чтобы прикрепить; отпустите в воздухе — упадёт.

Кнопка **Камеру ко мне** ставит её в пределах досягаемости. В VR сохраните ракурс так: Новый ракурс → Камеру ко мне →
взять, поставить, отпустить.

## Настройки и помощь

Откройте настройки через меню паузы с Cloth Config или измените `config/vrcamera.json` и выполните `/vrcam reload`.
Фото сохраняются в `screenshots/vrcamera`, а на Windows также копируются в буфер обмена.

- Нет персонажа в VR: включите **Show Playermodel**.
- Чёрное окно зеркала VR: проверьте **Desktop Mirror**.
- Нет настроек: установите **Cloth Config**.
- Не работают клавиши: переведите фокус на нужное окно и закройте меню.
- Ошибка камеры: посмотрите `logs/latest.log`.

В [справочнике](docs/GUIDE_RU.md) описаны режимы, фото, команды, конфигурация и решение проблем.

## Известные ограничения

- Обновления Vivecraft могут нарушить совместимость с его внутренними классами.
- Для отдельного окна ПК нужен OpenGL; шейдеры не поддерживаются. Хромакей также не поддерживает графику Fabulous.
- Притягивание камеры в VR занимает кнопку взаимодействия этой руки и не учитывает стены.
- После сбоя во время съёмки временные значения камеры могут остаться в конфиге Vivecraft.

Подробности — в [справочнике](docs/GUIDE_RU.md#известные-ограничения).

## API плагина для серверов

Необязательный плагин **VRCamera** работает на **Paper 1.21.4+ / Java 21** и передаёт фото и положение камер.
Другие плагины могут слушать `PhotoPinEvent` (отменяемое) и `PhotoTakeEvent` из `ru.deelter.vrcamera.sync.plugin.event`.
Добавьте `depend: [VRCamera]` или `softdepend: [VRCamera]` в `plugin.yml`.
`/vrcamsync list <игрок>` показывает закреплённые фото игрока.
См. [настройку сервера](docs/GUIDE_RU.md#общие-фото-на-сервере).

## Сборка

```bash
./gradlew build
./gradlew build -Pmc=26.3
./gradlew buildAll
```

Команды собирают версию по умолчанию, 26.3 или все поддерживаемые версии. Мод и необязательный
`vrcamera-paper-plugin-<версия>.jar` появляются в `build/libs/`.
Версия Minecraft по умолчанию задаётся в [`gradle.properties`](gradle.properties), зависимости — в [
`versions/`](versions/).
