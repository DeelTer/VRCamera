# VRCamera

Аддон для [Vivecraft](https://modrinth.com/mod/vivecraft): превращает ручную (handheld) камеру Vivecraft в оператора,
который сам снимает игрока от третьего лица. Сделан для стримов и записи через OBS.

- **Режиссёр**: сам выбирает ракурсы и переключает их, как кинематографическая камера в GTA.
- **Следование**: камера держится там, куда её поставили рукой, относительно игрока.
- Камера не залезает в блоки, всегда видит игрока и направлена в центр тела.
- Учитывает атрибут `scale`: все дистанции умножаются на размер игрока.

## Требования

| | |
|---|---|
| Minecraft | 26.2 |
| Загрузчик | Fabric Loader 0.19.5+ и Fabric API |
| Vivecraft | 1.3.13+ (собрано с 26.2-1.3.15) |
| Java | 25 |

Только клиент. Работает только в стоячем VR-режиме: в сидячем (seated) Vivecraft отключает ручную камеру.

## Сборка

```bash
./gradlew build
```

Готовый мод: `build/libs/vrcamera-1.0.jar`. Проекту нужен Gradle 9.7.0, wrapper в репозитории уже настроен на него.

## Как пользоваться

1. Зайти в мир в VR.
2. Нажать `F8` или кнопку **VR-камера** в меню паузы. Режимы идут по кругу: Выкл → Режиссёр → Следование.
3. В OBS захватить окно Minecraft. Пока камера включена, зеркало на рабочем столе показывает её картинку (16:9).

Режим зеркала в настройках Vivecraft не должен быть «Off»: тогда Vivecraft не рисует зеркало вообще.

Разрешение картинки задаётся в настройках Vivecraft (Camera Resolution), а не этим модом.

### Управление

| Действие | Клавиша | В VR |
|---|---|---|
| Переключить режим | `F8` | кнопка в меню паузы |
| Следующий план | `F9` | кнопка в меню паузы |
| Удерживать текущий план | `F10` | кнопка в меню паузы |
| Следующий свой ракурс | `F7` | кнопка в меню паузы |
| Новый свой ракурс | не назначена | кнопка в меню паузы |
| Удалить свой ракурс | — | кнопка в меню паузы |
| Отладочный оверлей | не назначена | кнопка в меню паузы |

Это обычные привязки клавиш: их можно переназначить в настройках управления и привязать к кнопкам контроллеров
в привязках SteamVR. Клавиатурой может управлять и другой человек, пока игрок в шлеме.

### Поставить камеру рукой

Камеру можно взять рукой, как обычную камеру Vivecraft, и поставить в любое место.

- В режиме **Следование** она останется в этой точке относительно игрока. Позиция сохраняется в конфиг.
- В режиме **Режиссёр** она продержит этот ракурс `manualHoldSeconds` секунд, затем режиссёр продолжит сам.

Камера запоминает только позицию. Направление она выбирает сама: всегда смотрит на игрока.

### Свои ракурсы

Поставленных рукой ракурсов может быть несколько.

- **Новый ракурс** создаёт копию текущего и делает её активной. После этого камеру нужно переставить рукой:
  новая позиция запишется в этот ракурс.
- **Следующий свой ракурс** переключает их по кругу, камера плавно перелетает.
- **Удалить ракурс** удаляет активный. Последний удалить нельзя.

Позиция, поставленная рукой, всегда записывается в активный ракурс.

### Метка камеры

В шлеме на месте камеры видна красная точка с подписью `REC` и названием текущего плана. В записи её нет:
она рисуется только для глаз игрока. За точку камеру можно взять рукой так же, как за модель.

Поле `marker` в конфиге: `"dot"` — точка, `"model"` — модель камеры Vivecraft с экранчиком, `"none"` — ничего.

### Отладочный оверлей

Показывает на HUD, что делает камера: режим, текущий план и его время, причину последней смены, ситуацию,
насколько камера прижата стенами, цель в бою. Нужен для подбора значений в конфиге.

## Ракурсы

| Ключ | Что делает | Когда выбирается чаще |
|---|---|---|
| `shoulder` | сзади, из-за плеча | движение, полёт, тесные места |
| `front` | спереди, пятится перед игроком | простой, ходьба |
| `orbit` | медленно облетает игрока по кругу | простой, бой |
| `flyby` | стоит впереди по пути и провожает игрока поворотом, с зумом | бег, полёт, езда |
| `crane` | поднимается высоко позади игрока | открытые места, полёт |
| `low` | от земли, снизу вверх | бой, бег |
| `hands` | крупный план рук | копание, простой |
| `duel` | из-за плеча игрока на противника, оба в кадре | бой, когда есть цель |
| `death` | облёт погибшего игрока с отъездом | только при смерти |
| `fall` | почти отвесно сверху | только при долгом падении |
| свой | ракурс, поставленный рукой | режим «Следование» |

`front` медленно наезжает на игрока, пока тот стоит на месте.

Режиссёр определяет, чем занят игрок (стоит, идёт, бежит, летит на элитрах, едет верхом, плывёт, дерётся, копает),
и находится ли он в тесном месте. От этого зависят шансы ракурсов и дистанции.

Смена ракурса бывает двух видов:

- **Склейка**: камера сразу оказывается в новой точке.
- **Пролёт**: камера плавно облетает игрока по дуге до новой точки.

Ракурс меняется, когда вышло его время, когда стена закрыла игрока или когда изменилась ситуация.
При телепорте камера прыгает вместе с игроком и сохраняет ракурс; только `flyby` заменяется.

### Бой

Цель — тот, кого игрок ударил. Если игрок получил урон, а цели нет, берётся ближайший враждебный моб.
Цель сбрасывается через 5 секунд без боя, при её смерти или если она далеко.

В плане `duel` камера встаёт за игроком со стороны, противоположной цели, отъезжает тем дальше, чем дальше цель,
и целится в точку между ними. Поле `azimuth` у него отсчитывается от направления на цель, а не от взгляда игрока.

### События

- **Смерть**: план `death` держится до возрождения.
- **Долгое падение** (больше 5 блоков): план `fall` держится до приземления и ещё секунду после.
- **Взлёт на элитрах**: у `flyby` повышенный шанс на следующую смену плана.

События отключаются полем `events`. Удержание плана (`F10`) тоже их отключает.

### Композиция

Когда игрок движется, камера целится немного впереди него, чтобы в кадре было больше места по ходу движения.
Настраивается полями `leadRoom` и `leadRoomMax`; `leadRoom: 0` возвращает наведение строго в центр тела.
В планах `hands` и `duel` это не применяется.

## Как камера избегает блоков

- От центра тела к желаемой точке пускаются 8 лучей (углы небольшого куба вокруг камеры). Если на пути блок,
  камера встаёт перед ним. Поэтому между камерой и центром тела всегда свободно.
- Придвигается камера мгновенно, отодвигается обратно плавно.
- Тонкое препятствие (не толще блока: ствол, столб, край стены) камера до `softOcclusionTime` секунд игнорирует
  и смотрит мимо, если сама при этом стоит в свободном месте. В блок она не заходит никогда.
- Если стены прижали камеру слишком близко дольше `occlusionCutTime` секунд, режиссёр меняет ракурс.
- При выборе ракурса отбрасываются точки в стене и слишком близкие к игроку. Точки, откуда не видно голову или
  которые находятся под водой при игроке над водой (и наоборот), получают штраф.

## Конфиг

Файл `config/vrcamera.json` создаётся при первом включении камеры. Перечитывается при каждом включении из режима «Выкл».

### Общие настройки

| Поле | По умолчанию | Значение |
|---|---|---|
| `forceMirror` | `true` | показывать картинку камеры на зеркале, пока камера включена |
| `marker` | `"dot"` | метка камеры в шлеме: `"dot"`, `"model"` или `"none"` |
| `markerLabel` | `true` | подпись с названием плана рядом с точкой |
| `markerSize` | `14` | размер точки |
| `debugOverlay` | `false` | отладочный оверлей на HUD |
| `aimHeight` | `0.6` | куда целиться: 0 — ноги, 1 — голова |
| `positionLag` | `0.35` | секунд, за которые камера догоняет нужную позицию |
| `lookLag` | `0.12` | секунд, за которые прицел догоняет игрока |
| `turnLag` | `0.9` | секунд, за которые камера облетает игрока при его повороте |
| `turnDeadzone` | `12` | на сколько градусов можно повернуться, не сдвинув камеру |
| `speedFov` | `true` | расширять угол обзора на большой скорости |
| `leadRoom` | `0.25` | на сколько секунд движения вперёд целится камера; 0 — выключено |
| `leadRoomMax` | `0.8` | предел этого смещения, в размерах игрока |
| `collisionRadius` | `0.15` | отступ камеры от стен, в блоках |
| `collisionMargin` | `0.12` | дополнительный отступ от блока на пути |
| `softOcclusionTime` | `0.35` | сколько секунд игнорировать тонкое препятствие; 0 — выключено |
| `occlusionRatio` | `0.45` | доля дистанции, ближе которой камера считается зажатой |
| `occlusionCutTime` | `0.6` | секунд в зажатом состоянии до смены ракурса |
| `transition` | `"auto"` | `"auto"`, `"cut"` (только склейки) или `"blend"` (только пролёты) |
| `blendChance` | `0.6` | шанс пролёта вместо склейки при `"auto"` |
| `minShotTime` | `2.5` | минимум секунд до смены ракурса из-за изменения ситуации |
| `manualHoldSeconds` | `20` | сколько режиссёр держит ракурс, поставленный рукой |
| `orbitSpeed` | `14` | скорость облёта, градусов в секунду |
| `events` | `true` | особые планы для смерти и падения |
| `activePreset` | `0` | номер активного своего ракурса, считая с нуля |
| `customInRotation` | `false` | включить свои ракурсы в ротацию режиссёра |

### Настройки ракурса

Блок `shots` содержит по записи на ракурс, список `presets` — ракурсы, поставленные рукой.

| Поле | Значение |
|---|---|
| `enabled` | использовать ли ракурс |
| `weight` | относительный шанс выбора |
| `azimuth` | градусы вокруг игрока: 0 — спереди, 180 — сзади. Сторона (лево/право) выбирается случайно |
| `elevation` | градусы над горизонтом |
| `distance` | дистанция в блоках для игрока обычного размера |
| `fov` | угол обзора |
| `minDuration`, `maxDuration` | длительность плана в секундах |

Для `flyby` поле `distance` задаёт, насколько далеко впереди встаёт камера, а `azimuth` и `elevation` не используются.

## Ограничения

- **В шлеме не проверено.** Мод собирается и загружается вместе с Vivecraft, математика поворота проверена
  отдельно, но поведение ракурсов в игре не тестировалось. Значения по умолчанию подобраны на глаз.
- Мод использует внутренние классы Vivecraft (`ClientDataHolderVR`, `CameraTracker`, `VRSettings`), а не только
  публичный API. Новая версия Vivecraft может его сломать.
- Камера — это дополнительный полный рендер мира. FPS упадёт так же, как при обычной включённой камере Vivecraft.
- Поза камеры отстаёт на один кадр: Vivecraft считывает её до запуска трекеров.
- Пока камера включена, мод меняет настройки Vivecraft «Camera FOV» и вывод камеры на зеркало. При выключении
  и при выходе из игры они возвращаются.
- Метка камеры и подпись рисуются отладочными примитивами Minecraft. Их размер в шлеме не проверен,
  подбирается полем `markerSize`.
- Не сделано: экран настроек в игре, отдельные клавиши для каждого ракурса.

## Устройство кода

| Пакет | Что внутри |
|---|---|
| `client` | `CameraController` — трекер Vivecraft, вызывается раз в кадр; `VrcameraClient` — клавиши, кнопки, оверлей |
| `client.director` | `Director` — выбор и смена ракурсов, определение ситуации, цель в бою, события |
| `client.shot` | `Shot`, `ShotType` — где ракурс хочет видеть камеру |
| `client.rig` | `Rig` — сглаживание, коллизии, наведение; `Subject` — данные об игроке; `WorldProbe` — лучи |
| `client.config` | чтение и запись `vrcamera.json` |
| `client.math` | пружины и векторная математика |
| `mixin.client` | замена модели камеры на метку |
